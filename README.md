# cmd-3D_wireframe_viewer
A program that lets you view the wireframe of obj files in the terminal on Windows.
DISCLAMIER:

The object has to have only the vertex data in it. 

Anything like normal data will brick the program.

might add support later but probably won't

CONTROLS:
arrows -> movement
O ->  spawning  mode
H -> view plane before drawing 
Space -> spawning plane
R_F -> up and down camera rotation 
D-G -> 
J-K ->  wireframe left to right rotation
L-< -> wireframe up and down rotation
N-M -> wireframe roll rotation
